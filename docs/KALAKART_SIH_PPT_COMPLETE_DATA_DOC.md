### 📝 Exact Copy-Paste Content for Slide 3

#### [TOP SECTION: 5-Step End-to-End Implementation Pipeline]
1. **Input:** Artisan captures 1 craft photo & speaks 1 natural sentence in Hindi (*e.g., "Banarasi dupatta, 2 din lage, 350 raw material"*).
2. **AI Vision & Auto-Catalog:** `rembg` (U2-Net) removes messy background; Groq Llama-3.3 70B generates bilingual title, description & heritage story; Hindi TTS verifies aloud.
3. **Trend Intelligence & Fair Wage Engine:** Analyzes live marketplace search velocity signals + computes $\text{Cost Floor} = \text{Raw Material} + (\text{Labor Hours} \times ₹100/\text{hr}) + \text{Packaging}$.
4. **Multi-Channel Dispatch:** Generates ASIN for Amazon, FSN for Flipkart, GeM tender payload, Etsy USD ($), and ONDC Beckn JSON.
5. **Live Commerce Sync:** Dual-screen architecture demonstrates buyer purchasing on Paytm/Amazon and instant UPI order chime on the artisan’s phone.

#### [BOTTOM LEFT: Technology Stack]
* **Client Layer (Artisan PWA):** Mobile-first PWA (<2MB), HTML5, Tailwind CSS, Web Speech API (voice-to-text), WebRTC camera stream.
* **Backend & API Gateway:** Python 3.11, FastAPI (high-throughput async ASGI), SQLAlchemy ORM, SQLite/PostgreSQL, strict Pydantic v2 schemas.
* **AI Vision & Generative LLM:** `rembg` (U2-Net background removal), PIL image compositing, Groq Llama-3.3 70B (bilingual catalog generation), `gTTS` (native Hindi audio synthesis).
* **Market Intelligence & Protocols:** Craft Trend Intelligence Engine, Beckn Protocol v0.9.3 (ONDC), Amazon SP-API (`HANDMADE_PRODUCT`), ReportLab (Mela Standee PDF), `qrcode` (Dynamic UPI QR).
